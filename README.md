# Бот для определения степени облысения

Телеграм-бот для определения степени облысения по шкале Норвуда-Гамильтона с использованием глубокого обучения и модели MobileNetV2.

## О проекте

Этот проект представляет собой Telegram-бота, который может классифицировать изображения головы человека по степени облысения, используя шкалу Норвуда-Гамильтона (7 классов). Бот построен на основе нейронной сети MobileNetV2, обученной на специально подготовленном наборе данных.

### Шкала Норвуда-Гамильтона

Шкала Норвуда-Гамильтона - это система классификации мужского облысения (андрогенной алопеции), которая включает 7 стадий:

1. **Стадия 1**: Нет видимого облысения, нормальная линия роста волос
2. **Стадия 2**: Небольшой отступ линии волос в височной области, M-образная форма
3. **Стадия 3**: Глубокий отступ линии волос в височной и лобной области
4. **Стадия 4**: Более выраженное облысение с небольшой полосой волос между передней и задней лысиной
5. **Стадия 5**: Более крупные залысины с узкой полосой редких волос, разделяющей их
6. **Стадия 6**: Залысины на макушке и спереди соединились, полоса волос между ними отсутствует
7. **Стадия 7**: Наиболее тяжелая форма облысения, остались только волосы по бокам и сзади головы

## Установка и настройка

### Требования

- Python 3.12 или выше
- PyTorch 2.6.0 или выше
- torchvision 0.21.0 или выше
- python-telegram-bot 22.0 или выше
- Другие зависимости из файла `requirements.txt`

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/hairloss_bot.git
cd hairloss_bot
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Windows
venv\Scripts\activate
# Для Linux/Mac
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте базу данных:
```bash
# Создайте файл database/settings.py с настройками БД
# Пример содержимого:
DB_URL = "sqlite:///hairloss.db"
BOT_TOKEN = "ваш_токен_телеграм_бота"
```

## Использование

### Подготовка данных и обучение модели

1. Организуйте данные по классам:
```bash
python organize_classes.py
```

2. Обучите модель MobileNet:
```bash
python model/train_mobilenet.py
```

3. После обучения модель будет сохранена в файл `model/mobilenet_hairloss_model.pth`

### Запуск Telegram-бота

1. Получите токен для Telegram-бота у [@BotFather](https://t.me/BotFather) и добавьте его в `database/settings.py`

2. Запустите бота:
```bash
python run_bot.py
```

3. Откройте бота в Telegram и начните взаимодействие с ним, отправив команду `/start`

### Использование модели для предсказания на отдельных изображениях

```bash
python model/predict.py --image путь_к_изображению --model model/mobilenet_hairloss_model.pth
```

## Примеры использования

1. Отправьте боту фотографию головы (требуется фото сверху)
2. Бот проанализирует изображение и определит степень облысения
3. Вы получите результат с описанием стадии и визуализацией, включающей вероятности для каждого класса
